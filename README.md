# 🧠 CyberMind AI Game

**CyberMind AI** is an AI-powered cybersecurity maze game developed using Python and Pygame. It combines artificial intelligence, intelligent pathfinding, and interactive gameplay to create an engaging cybersecurity gaming experience.

## 🚀 Features

- 🎮 Manual and Automatic Gameplay Modes
- 🤖 Intelligent Security Bots
- 🧭 A*, BFS, and DFS Pathfinding Algorithms
- 🔄 Dynamic Pathfinding and Obstacle Avoidance
- 🔐 Cybersecurity-Based Puzzles
- 🔑 Key Collection and Maze Exploration
- ❤️ Health, Score, and Timer System
- 📊 AI Path Visualization
- 🎯 Multiple Difficulty Levels
- 📴 Offline Desktop Gameplay

## 🛠️ Technologies Used

- Python
- Pygame
- Artificial Intelligence
- A* Search Algorithm
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## 🎯 Game Objective

Navigate through challenging mazes, solve cybersecurity puzzles, collect keys, avoid security bots, and reach your destination. Compare different AI pathfinding algorithms and explore intelligent navigation.

## 💻 Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd CyberMind-AI
   ```

3. Install dependencies:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python main.py
   ```

## 🧪 AI Algorithms

| Algorithm | Purpose |
|---|---|
| A* Search | Optimal pathfinding using heuristics |
| BFS | Explores paths level by level |
| DFS | Explores paths depth-first |
